# KaoJanken Webapp

## ソフトウェアについて

授業「感性情報処理論・演習」の最終課題の作品です。

## 依存関係

-   コンピューターに`uv`がインストールされている必要があります
-   コンピューターに`Node.js`がインストールされている必要があります
-   コンピューターに`pnpm`がインストールされている必要があります

## はじめに

以下を実行してください

```sh
pnpm sync
```

## アプリケーションの実行

以下を実行してください

```sh
pnpm start
```

> [!tip]
> ポート番号は、[`.env`](.env)から編集できます。
