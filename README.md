# KaoJanken Webapp

## ソフトウェアについて

授業「感性情報処理論・演習」の最終課題の作品です。

## 必要なもの

-   コンピューターに[`mise`](https://mise.jdx.dev/)がインストールされている必要があります

## はじめに

以下を実行してください

```sh
mise run sync
```

## アプリケーションの実行

以下を実行してください

```sh
mise run start
```

> [!tip]
> ポート番号は、[`.env`](.env)から編集できます。
